# Nexlane Digital

Official website of **Nexlane Digital** — a digital marketing and web agency based in Kaithal, Haryana, India.

This repository is for the website project. Work happens on feature branches merged into `main` via pull requests (branch protection is enabled).

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev
```

## Contributing

1. Create a feature branch from `main`.
2. Commit your work with clear, technical messages.
3. Open a pull request — CI (lint + build) must pass before merge.
